Spot the Seasons is a complete spot-the-difference game in pure vanilla JavaScript: six hand-painted procedural scenes (Spring Fair, Summer Pier, Autumn Market, Winter Square, Night Carnival, Grand Finale), seven sneaky differences per picture, a race against the clock, hints with a time penalty, sound synthesised with WebAudio, and full mouse and keyboard play.

## Run it

```sh
node serve.ts
```
